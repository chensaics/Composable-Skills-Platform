# csp-workspace — 工作套件/效率工具 包

本目录是 workspace 子包的内部目录结构占位。正式拆包时：
- workspace-meta/     → 知识管理方法论、GTD、第二大脑
- workspace-workflow/ → 工作流水线：capture → organize → execute → reflect
- workspace-patterns/ → Notion/Obsidian/Linear/飞书/WeChat/Slack API
- workspace-runtime/  → 自动同步、消息推送、日程提醒

设计原则: Skills 链接外部产品 API，不构建它们。
